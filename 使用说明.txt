PixivRenamer 1.0.0 使用说明
================================
项目主页：https://github.com/CYHY-MK/PixivRenamer
作者：CYHY-MK        许可：MIT

声明：本工具仅用于整理你自己合法下载、自己有权处理的图片。请遵守 pixiv、
SauceNAO、ascii2d 等网站的服务条款，控制请求频率，不要用于大规模爬取、
商业用途或任何侵犯版权的行为。使用产生的一切后果由使用者自行承担。

一、运行
1. 便携版：到项目主页 Releases 下载最新 PixivRenamer_v1.0.0_portable.zip，
   解压后双击 PixivRenamer\PixivRenamer.exe。
2. 免安装部署：双击安装到本用户.bat，会把程序复制到
   %LOCALAPPDATA%\Programs\PixivRenamer 并创建开始菜单快捷方式；
   卸载运行卸载本用户安装.bat。
3. 本程序是自包含单文件 exe，不需要安装 .NET / Python / VC++ 运行库。
   如果 Windows SmartScreen 提示，请右键 exe -> 属性 -> 解除锁定，或选择仍要运行。
4. 本程序默认以管理员身份启动（双击后会弹一次 UAC 确认框），原因见第六节。
   不想提权时：在「整理」页底部取消勾选「默认以管理员身份启动」并保存配置，
   或启动时加 --no-elevate；命令行（--cli）与自检（--selftest）本来就不会提权。
5. 启动后会自动检查 GitHub 上是否有新版本（可在界面关闭），
   也可以从「帮助 -> 检查更新」或「关于」窗口手动检查。

二、快速开始
1. 打开程序，在「整理」页选择源文件夹（可直接把文件夹拖进窗口，或手动粘贴路径）。
2. 第一次建议勾选预览模式（不修改文件），点击开始整理。
   日志区会显示扫描、pixiv 查询、识图进度与限流冷却；结束后点击查看报告。
3. 确认结果无误后，取消预览模式再执行；程序会弹窗二次确认。
4. 查询 R-18 / 受限作品时，在「pixiv / 识图」页填写浏览器 Cookie。

三、各页说明
 整理
  - 源文件夹 / 输出目录 / 复制或移动 / 递归 / 隐藏文件
  - 分类方式、命名模板、预览模式、断点续跑、报告文件
  - 未识别文件单独归类：正式执行时把认不出作者/标题的图片按原名收进
    「未识别」文件夹（文件夹名可改），原名不变、原因写进报告
 pixiv / 识图
  - Cookie、代理、线程、间隔、超时、重试、查询缓存
  - SauceNAO / ascii2d 识图回退、API Key、相似度下限、上传上限
  - 中置信度结果用感知哈希复核（推荐保持开启）+ 距离上限
  - 近似重复图只查一次识图（按 dHash 合并同一张图的不同分辨率）
  - pixiv 不可达时仍尝试识图（识图接口与 pixiv 不同域名，建议开启）
  - 请求缓冲：识图请求排队送出，并发上限默认 1（完全串行），
    被 429/503 限流时全局冷却（默认 12 秒起、按指数退避、最高 120 秒），
    冷却期间界面上会显示「识图冷却」进度；识图没结果会按「失败重试」次数退避重试
 任务与日志
  - 顶部四个计数卡：任务记录 / 已识别 / 未识别 / 失败
  - 实时日志、最近任务卡片、保存配置、重新加载配置、运行自检、打开日志文件

四、目录说明
  PixivRenamer.exe     主程序（自包含，无需运行库）
  PixivRenamer.json    配置文件（包含 Cookie，请注意保密）
  Logs\                运行日志
  cache\               查询缓存（可删除，程序会自动重建）
  <源目录>\未识别\      未识别图片归档（可在界面上改名字或关闭）
  <源目录>\_unresolved.txt  未识别清单（按原因分类）
  <源目录>\_pixiv_rename_report.csv  改名/复制报告（可直接用于 --undo）

五、识图与应用
1. 程序默认「自动侦测」本地代理，一般什么都不用填。如果 pixiv 打不开：
   先确认 Clash / v2rayN 已启动且浏览器能打开 pixiv，然后在「pixiv / 识图」页
   点「检测本地代理」，它会列出所有候选端口并告诉你哪个能用。
2. 代理模式四选一：自动侦测（推荐）/ 手动指定代理 / 使用系统代理 / 直连。
   最常见的错误是端口填错：Clash Verge 默认 7897，Clash for Windows 默认 7890；
   在 Clash 的「设置 -> 端口」里能看到 mixed-port 的实际值。
3. 点「测试网络」失败时会弹出详情窗口（代理解析 + 三站点连通性 + 处理建议），
   同时把报告写到 exe 同目录的 error-reports\网络诊断_时间戳.txt，可直接发给作者定位。
4. 命令行诊断：PixivRenamer.exe --test-net
5. 自动获取 Cookie：填写 pixiv 账号、密码，点自动获取 Cookie。
   如果 pixiv 要求人机验证/邮箱验证，请点打开 pixiv 登录页在浏览器登录后，
   按 F12 -> 网络 -> 复制请求头里的 Cookie，粘贴到 Cookie 输入框。
6. SauceNAO 现在必须填写 API Key，匿名调用会被直接拒绝；免费 Key 获取：
   https://saucenao.com/user.php?page=account
   ascii2d 无需 Key：https://ascii2d.net/
   程序界面中已提供这两个可点击链接。
7. ascii2d 前置 Cloudflare 人机校验。如果你的网络过不了校验，日志会提示
   「ascii2d 被 Cloudflare 人机校验拦截」，这时换网络/挂代理，或只用 SauceNAO。
8. 识图命中后：置信度 >=85 直接采用；60~85 会下载来源缩略图和本地图做感知哈希
   比对，对不上就丢弃（避免同角色/相似构图被误判成同一张图）。
9. 如果 pixiv 打不开但 SauceNAO 能连上，程序仍会用识图结果重命名（作者/标题来自识图），
   此时建议先开预览模式核对 CSV 报告。

六、管理员权限（默认开启）
1. 为什么：程序需要打开浏览器、把 Cookie 复制到输入框；当浏览器是「以管理员身份运行」
   （高完整性级别）时，普通权限的程序无法与它交互，所以默认以管理员身份启动。
2. 界面上怎么看：整理页底部「权限与管理员启动」卡片显示「当前：管理员」或
   「当前：普通用户」；点「以管理员重启」可立刻提权重启（会弹 UAC）。
3. 拒了 UAC 怎么办：程序不会退出，本次以普通权限运行，日志里会有提示；
   需要时再点「以管理员重启」，或右键 exe -> 以管理员身份运行。
4. 也可以不用程序内提权：右键 exe -> 属性 -> 兼容性 -> 勾选「以管理员身份运行」。
   注意该设置只对这一个路径生效，便携版换目录后要重新设置。
5. 副作用：以管理员身份运行时，程序写出的日志 / 缓存文件属主是管理员。
   若希望这些文件归自己所有，取消「默认以管理员身份启动」即可。

七、未识别图片怎么办
1. 正式执行后，认不出作者/标题的图片会按原名收进「未识别」文件夹（预览模式不动文件）。
2. 点「未识别清单」或打开 _unresolved.txt，可以看到每个文件的原因分类：
   识图无结果 / 识图复核未通过 / 识图限流待重试 / 识图服务不可用 /
   PID 查询无结果 / pixiv 查询失败 / 文件过大或无法读取 / 无 PID 且识图无结果。
3. 想重试这些图：把它们从「未识别」文件夹移回源文件夹（或把源目录指向该文件夹），
   补好代理 / API Key 后再跑一次。
4. 不想分类归档：取消勾选「未识别文件单独归类」，它们会保持原样，只写进报告。

八、检查更新
  1. 启动后会自动查询 GitHub 上的最新版本，发现新版本才弹窗（含更新说明与下载链接）。
     不想每次检查：在「整理」页底部取消勾选「启动时自动检查更新」并保存配置。
  2. 手动检查：「帮助 -> 检查更新」，或「关于 PixivRenamer」窗口里的「检查更新」按钮。
  3. 命令行：PixivRenamer.exe --check-update
  4. 项目地址 / 作者 / 许可 / 声明都可以在「关于 PixivRenamer」和「帮助」菜单里看到。

九、命令行（高级）
  PixivRenamer.exe --version
  PixivRenamer.exe --check-update
  PixivRenamer.exe --selftest
  PixivRenamer.exe --test-net
  PixivRenamer.exe --test-net --proxy 127.0.0.1:7897 --proxy-mode explicit
  PixivRenamer.exe --cli "D:\pixiv" --dry-run --limit 20
  PixivRenamer.exe --cli "D:\pixiv" --yes
  PixivRenamer.exe --cli --undo "D:\pixiv\_pixiv_rename_report.csv"
  识图缓冲：--reverse-concurrency N（默认 1） / --no-reverse-queue
  未识别归类：--unresolved-folder 目录名 / --no-unresolved-folder
  界面不提权：--no-elevate（--cli / --selftest 本来就不提权）

十、出问题时
  1. exe 同目录的 error-reports\ 里会有网络诊断报告（含代理检测、连通性、最近日志）。
  2. Logs\PixivRenamer.log 是运行日志。
  3. 到项目 Issues 反馈并附上上面两个文件，基本就能定位问题：
     https://github.com/CYHY-MK/PixivRenamer/issues
